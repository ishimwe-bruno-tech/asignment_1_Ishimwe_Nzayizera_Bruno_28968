## Scenario

Sunrise Supermarket is a retail store that sells different types of products, including groceries and household goods. Customers from different locations visit the supermarket to purchase products.

The supermarket keeps records of customers, orders, products, and the individual items included in each order. The database can be used to examine customer purchases, spending patterns, order history, and overall revenue.

## 1. Customer Orders

### Task

Display each order together with the customer's name, city, and the date when the order was placed.

```sql
SELECT
    o.order_id,
    c.customer_name,
    c.city,
    o.order_date
FROM customers c
JOIN orders o
    ON c.customer_id = o.customer_id
ORDER BY o.order_date;
```

## 4. Customers Spending Above Average

### Task

Calculate the total amount spent by every customer and display customers whose spending is higher than the average.

```sql
WITH spending_summary AS (
    SELECT
        o.customer_id,
        SUM(oi.quantity * p.price) AS total_spent
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY o.customer_id
)
SELECT
    c.customer_id,
    c.customer_name,
    ss.total_spent
FROM spending_summary ss
JOIN customers c
    ON c.customer_id = ss.customer_id
WHERE ss.total_spent > (
    SELECT AVG(total_spent)
    FROM spending_summary
)
ORDER BY ss.total_spent DESC;
```

## 5. Customer Spending Ranking

### Task

Rank customers according to the total amount they have spent, beginning with the highest total.

```sql
WITH spending_summary AS (
    SELECT
        o.customer_id,
        SUM(oi.quantity * p.price) AS total_spent
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY o.customer_id
)
SELECT
    c.customer_name,
    ss.total_spent,
    RANK() OVER (
        ORDER BY ss.total_spent DESC
    ) AS spending_rank
FROM spending_summary ss
JOIN customers c
    ON c.customer_id = ss.customer_id
ORDER BY spending_rank;
```

## 6. Customer Order Sequence

### Task

Assign a sequence number to each customer's orders based on the date they were placed.

```sql
SELECT
    o.customer_id,
    c.customer_name,
    o.order_id,
    o.order_date,
    ROW_NUMBER() OVER (
        PARTITION BY o.customer_id
        ORDER BY o.order_date
    ) AS order_number
FROM orders o
JOIN customers c
    ON o.customer_id = c.customer_id
ORDER BY
    o.customer_id,
    o.order_date;
```

## 7. Running Revenue

### Task

Calculate the revenue generated by each order and display the accumulated revenue according to the order date.

```sql
WITH order_revenue AS (
    SELECT
        o.order_id,
        o.order_date,
        SUM(oi.quantity * p.price) AS order_revenue
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY
        o.order_id,
        o.order_date
)
SELECT
    order_id,
    order_date,
    order_revenue,
    SUM(order_revenue) OVER (
        ORDER BY order_date, order_id
    ) AS running_revenue
FROM order_revenue
ORDER BY
    order_date,
    order_id;
```

## 8. Days Between Customer Orders

### Task

For customers who have placed more than one order, determine the number of days between each order and the previous order.

```sql
WITH order_history AS (
    SELECT
        customer_id,
        order_id,
        order_date,
        LAG(order_date) OVER (
            PARTITION BY customer_id
            ORDER BY order_date
        ) AS previous_order_date
    FROM orders
)
SELECT
    customer_id,
    order_id,
    order_date,
    previous_order_date,
    order_date - previous_order_date AS days_between_orders
FROM order_history
WHERE previous_order_date IS NOT NULL
ORDER BY
    customer_id,
    order_date;
```
