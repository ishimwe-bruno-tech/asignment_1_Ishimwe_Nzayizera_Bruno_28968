# Scenario

Sunrise Supermarket is a retail store that sells different types of products, including groceries and household goods. Customers from different locations visit the supermarket to purchase products.

The supermarket records information about its customers, orders, products, and the individual items included in each order. The database can be used to examine customer purchases, spending patterns, order history, and overall revenue.

---

# 1. Customer Orders

### Task

Display each order together with the name of the customer, their city, and the date when the order was placed.

```sql
SELECT
    o.order_id,
    c.customer_name,
    c.city,
    o.order_date
FROM orders o
JOIN customers c
    ON o.customer_id = c.customer_id
ORDER BY o.order_date;
```

# 2. Order Item Details

### Task

Display information about the products included in each order, including the product name, category, price, and quantity purchased.

```sql
SELECT
    oi.order_item_id,
    p.product_name,
    p.category,
    p.price,
    oi.quantity
FROM order_items oi
JOIN products p
    ON oi.product_id = p.product_id
ORDER BY oi.order_item_id;
```

# 3. Customers and Their Orders

### Task

List every customer together with their orders. Customers who have not placed an order should also be included.

```sql
SELECT
    c.customer_id,
    c.customer_name,
    c.city,
    o.order_id,
    o.order_date
FROM customers c
LEFT JOIN orders o
    ON c.customer_id = o.customer_id
ORDER BY
    c.customer_id,
    o.order_date;
```

# 4. Customers Spending Above Average

### Task

Find the total amount spent by each customer and display only those customers whose spending is higher than the average customer spending.

```sql
WITH spending_summary AS (
    SELECT
        o.customer_id,
        SUM(oi.quantity * p.price) AS total_spent
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY o.customer_id
)
SELECT
    c.customer_id,
    c.customer_name,
    ss.total_spent
FROM spending_summary ss
JOIN customers c
    ON c.customer_id = ss.customer_id
WHERE ss.total_spent > (
    SELECT AVG(total_spent)
    FROM spending_summary
)
ORDER BY ss.total_spent DESC;
```

# 5. Customer Spending Ranking

### Task

Rank customers according to their total spending, starting with the customer who spent the highest amount.

```sql
WITH spending_summary AS (
    SELECT
        o.customer_id,
        SUM(oi.quantity * p.price) AS total_spent
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY o.customer_id
)
SELECT
    c.customer_name,
    ss.total_spent,
    RANK() OVER (
        ORDER BY ss.total_spent DESC
    ) AS spending_rank
FROM spending_summary ss
JOIN customers c
    ON c.customer_id = ss.customer_id
ORDER BY spending_rank;
```

# 6. Customer Order Sequence

### Task

Assign a number to each customer's orders according to the order in which they were placed.

```sql
SELECT
    o.customer_id,
    c.customer_name,
    o.order_id,
    o.order_date,
    ROW_NUMBER() OVER (
        PARTITION BY o.customer_id
        ORDER BY o.order_date
    ) AS order_number
FROM orders o
JOIN customers c
    ON o.customer_id = c.customer_id
ORDER BY
    o.customer_id,
    o.order_date;
```

# 7. Running Revenue

### Task

Calculate the revenue generated by every order and display the running total of revenue according to the order date.

```sql
WITH order_revenue AS (
    SELECT
        o.order_id,
        o.order_date,
        SUM(oi.quantity * p.price) AS order_revenue
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY
        o.order_id,
        o.order_date
)
SELECT
    order_id,
    order_date,
    order_revenue,
    SUM(order_revenue) OVER (
        ORDER BY order_date, order_id
    ) AS running_revenue
FROM order_revenue
ORDER BY
    order_date,
    order_id;
```

# 8. Days Between Customer Orders

### Task

For customers who have made more than one order, calculate the number of days between each order and the previous order.

```sql
WITH order_history AS (
    SELECT
        customer_id,
        order_id,
        order_date,
        LAG(order_date) OVER (
            PARTITION BY customer_id
            ORDER BY order_date
        ) AS previous_order_date
    FROM orders
)
SELECT
    customer_id,
    order_id,
    order_date,
    previous_order_date,
    order_date - previous_order_date AS days_between_orders
FROM order_history
WHERE previous_order_date IS NOT NULL
ORDER BY
    customer_id,
    order_date;
```
